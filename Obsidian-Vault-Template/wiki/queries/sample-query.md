# Sample Query (대규모 세션 로그 파싱 최적화 가이드)

## 문제 정의 및 배경
Claude Code 및 Antigravity(Gemini) 세션이 장기화되면 수십 MB에 달하는 대용량 JSONL 대화 로그가 누적됩니다. 이를 마크다운으로 파싱하고 옵시디언 볼트로 미러링할 때 발생하는 성능 저하와 유효성 검증 문제를 해결해야 합니다.

## 해결 절차 및 최적화 방법
1. **더미 세션 사전 필터링**:
   - 대화 턴 수가 1턴 미만이거나 파일 크기가 500바이트 이하인 빈 세션 파일은 파싱 대상에서 즉시 제외.
2. **증분 해시 비교 (MD5 Checksum)**:
   - 이전 파싱 시점의 파일 수정일자 및 MD5 해시를 기록하여, 변경된 세션만 선별적으로 변환.
3. **상대 경로 일괄 자동 변환**:
   - `file:///` 절대 경로 링크를 `../plans/` 및 `../chats/md/` 형태의 마크다운 상대 링크로 일괄 치환.

## 검증 결과
- 수백 건의 세션 로그 파싱 속도가 90% 이상 단축되며 옵시디언 볼트 내 인덱싱 부하가 해소됨.
